# OPEN CITY · 开放世界原型（Three.js + Rapier + Vite）

一个可玩的 GTA 式开放世界原型：第三人称角色、可驾驶汽车、分块流式加载的无限城市、会转弯会避让的交通 AI、任务系统与存档。

## 运行

需要 Node.js 18+（推荐 20+）。

```bash
npm install
npm run dev        # 浏览器自动打开 http://localhost:5173
```
Windows 可双击 `start.bat`，macOS/Linux 运行 `./start.sh`。
发布构建：`npm run build && npm run preview`（物理引擎 wasm 已内嵌，无需额外配置）。

## 第一单流程
1. 出生在街边，走到闪烁的**橙色轿车**旁，按 **E** 上车。
2. 沿东面大路开向小地图上的**黄点**，穿过几个路口，避让交通车辆；到达黄圈后减速停车。
3. 按 **E** 下车，步行进入黄色任务区域 → 获得 **$500**。
4. 之后自动生成无限的随机委托（报酬随距离增加）。
5. 随时刷新页面：金钱、任务进度、角色位置、你开过的车都会恢复（localStorage，每 2.5 秒自动存档）。

## 操作
| 按键 | 步行 | 驾车 |
|---|---|---|
| W/A/S/D | 移动 | 油门/倒车、转向 |
| Shift | 奔跑 | – |
| Space | 跳跃 | 手刹（可漂移） |
| 鼠标 | 环顾（点击画面锁定指针，Esc 暂停） | 同左，松开鼠标 1.3 秒后视角自动回到车尾 |
| E | 上车 | 下车（车速需低于 15 km/h） |
| R | – | 重置载具到最近车道（卡住时用） |
| 方向键 | 无鼠标时控制视角 | 同左 |

## 代码结构（src/）
| 文件 | 作用 |
|---|---|
| `config.js` | 路网常量（周期 80m、路宽 16m、靠右行驶车道）、随机数/哈希、数学工具 |
| `physics.js` | Rapier 初始化、无限地面 |
| `city.js` | **区块流式加载**：按玩家位置加载/卸载 7×7 区块；每区块程序化生成路面、标线、斑马线、建筑（合并几何 + 程序化窗户贴图）、路灯、树、静态碰撞体、路边停车；种子确定，同一区块永远一样 |
| `vehicles.js` | 车辆模型与街机式驾驶物理（动态刚体 + 自定义纵向/侧向/转向）、停放车辆管理（被开走的车会被记住） |
| `traffic.js` | 交通 AI：沿贝塞尔车道路径行驶，路口随机直行/左转/右转，前方锥形检测减速避让，死锁时短暂幽灵通过，环形区域动态生成/回收 |
| `player.js` | 角色（Rapier 胶囊体）、移动、跳跃、简单行走动画 |
| `missions.js` | 任务定义（手写首单 + 种子随机生成）、地面光柱标记、步骤状态机 |
| `hud.js` | HUD、朝向向上的圆形小地图 |
| `audio.js` | WebAudio 引擎声、碰撞声、完成提示音 |
| `save.js` / `input.js` / `main.js` | 存档、输入、渲染/相机（含相机碰撞）/主循环 |

## 可调参数
- 区块加载半径：`config.js` 的 `LOAD_R`；交通数量：`main.js` 中 `new Traffic(game, 26)`。
- 驾驶手感：`vehicles.js` 里 `MAX_F / ACC / MAXS / 抓地系数`。
- 想重来：开始菜单里点“清除存档并重新开始”。
