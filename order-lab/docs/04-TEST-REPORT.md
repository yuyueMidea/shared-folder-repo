## 四、复跑浏览器测试（可选）

一般启动不需要Playwright。需要复跑时额外安装：

```bash
npm install --no-save playwright@1.51.1
npx playwright install chromium --only-shell
```

终端一：`npm run dev -- --port 5173`；终端二：`node tests/browser-smoke.cjs`。测试固定访问127.0.0.1:5173，因此请确保该端口没有被其他服务占用。测试使用隔离浏览器，不改普通浏览器里的数据。

## 五、已知限制与未覆盖范围

- 没有在用户的Windows/Firefox环境直接运行；以Node构建和Chromium自动化验证为依据。
- localStorage只支持本地单标签演示，未做跨标签冲突协调、多人并发或真实服务端事务测试。
- 支付、退款、参团和物流是模拟，不验证第三方回调、实际到账或快递查询。
- 浏览器关闭时没有定时任务；再次加载时处理超时，不会后台持续运行。
- 仅1个SKU/订单、单包裹、整单全额售后；部分退款、换货、仲裁、图片上传与自动收货不在本期范围。
- 商品用系统emoji表示，字形/彩色效果取决于操作系统。中文依赖系统中文字体，Windows通常使用Microsoft YaHei，macOS使用PingFang SC。
- 未做全量可访问性审计、压力测试、安全渗透测试或所有表单错误组合穷举。
