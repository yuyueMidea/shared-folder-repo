# 街角漫游 · City Sandbox v1

一个可离线运行的 JavaScript / Three.js 第三人称开放城市原型。所有城市、车辆和人物均由代码生成，不依赖 CDN、外部模型、账号或后端。

## 直接运行（推荐先体验）

1. **完整解压 ZIP**，不要在压缩软件内打开。
2. 双击 `play/START.html`，使用开启硬件加速的桌面 Firefox、Chrome 或 Edge。
3. 点击「进入城市」。出生点就在配送站旁，先按 **F** 取件。
4. 走近橙色汽车，按 **E** 上车，跟随小地图黄色圆点前往目的地。
5. 松开油门或按空格停车，E 下车，在目标光圈内按 F 交付，获得 ¥200。

运行版已内嵌 JavaScript 和 CSS，无需安装 Node.js、无需联网。没有触屏操作支持。若本地文件的浏览器存储受到限制，仍可游玩，但不能保存；请改用下面的本地开发服务。不同浏览器、不同文件路径与 localhost 的存档互相独立。

## 源码运行

安装 Node.js 20.19+ 或 22+，在本目录打开终端：

```bash
npm install
npm run dev
```

打开终端给出的地址（通常为 http://127.0.0.1:5173）。构建和逻辑测试：

```bash
npm run build
npm test
```

`npm run build` 同时生成 `dist/` 静态站点和 `play/START.html` 离线文件。`dist/` 需 HTTP 静态服务，双击时请使用 `play/START.html`。

按用户偏好，压缩包不含 package-lock.json、node_modules。依赖版本直接固定在 package.json；npm install 默认会在本机生成锁文件，如不需要可使用 `npm install --package-lock=false`。

## 操作

| 按键 | 步行 | 驾驶 |
|---|---|---|
| W / S | 前进 / 后退 | 油门 / 刹车，继续按 S 倒车 |
| A / D | 横向移动 | 左 / 右转向 |
| Shift | 奔跑 | — |
| E | 靠近橙色车上车 | 低速时安全下车 |
| F | 取件 / 交付 | 提示先下车 |
| 空格 | — | 手刹 |
| 鼠标拖动 | 旋转相机 | 临时观察周围 |
| 双击场景 | 锁定鼠标视角 | 锁定鼠标视角 |
| Esc / 暂停按钮 | 暂停及菜单 | 暂停及菜单 |
| R | 移到附近道路 | 移到附近道路并停车 |

驾驶时不操作镜头会自动跟随车尾。锁定鼠标时按 Esc 释放；必要时再按一次暂停。存档每 8 秒及交互/暂停时保存。菜单中的「重新开始」需要确认后才删除存档。

## 已实现

- 第三人称角色、走跑动作、鼠标镜头和建筑遮挡检测。
- 一辆可驾驶汽车、速度相关转向、惯性、刹车、倒车和车轮动画。
- 安全上下车、建筑碰撞、交通车辆阻挡、道路复位。
- 96 米区块、确定性程序化城市、邻域加载与滞后卸载；区块内静态对象实例化。
- 20 辆简易直行交通车、跟车和两相位红绿灯；远处车辆循环再生成。
- 配送站、3 个轮换目的地、取件/交付/奖励完整流程。
- 小地图、距离提示、速度表、画质切换和性能面板。
- localStorage 本地存档、版本与数值校验、暂停/失焦处理。
- 固定 60 Hz 游戏模拟和有上限的补帧。

## 本版边界（请先阅读）

这是可玩的学习原型，不是完整 GTA。为了离线直开和降低第一版复杂度，本版**使用自定义二维平面碰撞与街机车辆，并未接入 Rapier**；无真实悬挂、坡道、跳跃、翻车和动力学推撞。碰撞车型简化为圆，可能在窄缝中较保守。交通只沿直线车道运行，无转弯、A*、复杂路口预约和绕障，极端情况下可能互相等待或出现交叉穿插。没有行人 AI、音效、枪战、警察、室内、联网。相机防遮挡为采样近似，并非完整物理形状扫描。

分块为本地程序生成/卸载，不是联网下载。地图以相同规则延伸，适合几公里范围探索；尚未实现浮动原点，不承诺无限远坐标精度。流畅档关闭阴影、降低像素比和区块半径。实际帧率取决于显卡、浏览器与分辨率。

## 目录

- `play/START.html`：内嵌资源的离线运行版。
- `src/main.js`：场景、输入、车辆、交通、任务、相机、存档与游戏循环。
- `src/world.js`：确定性区块描述、碰撞、存档校验等可测试纯函数。
- `src/style.css` / `index.html`：界面样式与结构。
- `scripts/standalone.mjs`：从构建产物生成离线 HTML。
- `tests/world.test.js`：核心逻辑回归测试。
- `docs/DESIGN.md`：架构和下一阶段建议。
- `docs/TEST-REPORT.md`：本次验证记录与限制。
- `THIRD-PARTY-NOTICES.txt`：Three.js 授权声明。

建议先体验本版，再按顺序拆分系统模块、引入 Rapier、完善路口和行人；不要先扩张素材数量。
